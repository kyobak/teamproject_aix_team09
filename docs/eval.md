# 평가 결과 / Evaluation

> D0·D1·D2 를 같은 테스트셋으로 비교하는 곳입니다(#15). 지금은 **D0(OpenCV 규칙, #5)** 결과만 있습니다.
> D0 는 정확도 목표 없이 YOLO(D1·D2)와 비교할 **기준선**입니다.

## 1. 테스트셋

| 항목 | 내용 |
|---|---|
| 영상 | 직접 촬영한 휴대폰 세로 영상 12개 (1080×1920, 30fps, 각 30~65초) |
| 장소 | ERICA 주변 횡단보도 4곳 (A·B·C·D), 장소마다 낮·해질녘·밤 |
| 평가 프레임 | 3프레임마다 1장 (초당 10장) → 약 5,300장 |
| 신호등 형태 | 모두 **세로 3칸** (위: 빨간 사람 / 가운데: 초록 사람 / 아래: 남은 시간 숫자) |
| 저장 위치 | 원본 영상은 저장소·공유 드라이브에 올리지 않음 (블러 전). 이 문서에는 숫자만 기록 |

**정답 매기는 법**: 사람이 1초에 1장씩 신호등 위치와 상태를 확인해 표시하고, 그 1초 안의 프레임은 같은 상태로 봅니다.
상태가 바뀌는 순간 앞뒤 0.3초, 추적이 불안정해 위치를 확신할 수 없는 구간은 평가에서 뺐습니다.

| 정답 상태 | 뜻 | 정답으로 인정하는 판정 |
|---|---|---|
| 빨강 | 위 칸 빨간 사람 켜짐 | `red` |
| 초록 | 가운데 칸 초록 사람 켜짐, 숫자 없음 | `green` |
| 점멸 | 남은 시간 숫자가 나오는 구간. 초록 사람이 1초마다 깜빡임(약 70% 켜짐) | `green` 또는 `off` |

**위치**: 판정한 박스의 중심이 정답 박스 근처(가로 ±0.5칸 폭, 세로 ±0.25칸 높이)에 있어야 맞힌 것으로 셉니다.
색이 맞아도 다른 신호등을 보고 맞힌 것은 틀린 것입니다.

## 5. 해석 (3줄)

1. 초록·점멸은 조명과 장소에 상관없이 잘 맞힌다. 신호등을 3칸으로 보고 숫자 칸을 빼서 점멸의 꺼진 순간을 `off` 로 낼 수 있다.
2. 빨강이 약한 이유는 대부분 **다른 신호등을 고른 것**(차량 신호등, 다른 방향 보행 신호등, 해질녘·밤 조명)이다. 색은 맞아도 위치가 틀린 경우가 빨강 정답의 24% 다.
3. 색과 모양 규칙만으로는 "여러 신호등 중 내 것"을 고르기 어렵다 → 차량 신호등을 따로 배우는 YOLO(D1·D2, `car_signal` 클래스)로 개선할 부분.

## 6. 한계

- 정답 박스는 추적으로 만든 근사치라, 위치 판정에 약간의 오차가 있다.
- 4곳 모두 같은 지역(ERICA 주변)이다. 다른 지역의 신호등 모양·설치 높이는 확인하지 못했다.
- 메신저로 옮긴 영상이라 압축으로 화질이 떨어져 있다.
- 평가에서 뺀 구간(카메라가 크게 움직이는 구간)에서 옆 신호등을 잡아 `green` 을 낸 사례를 확인했다 (영상 시작 직후 몇 초). 숫자에는 포함되지 않았다.
- 빨간불·점멸 중 **CROSS 안내** 횟수는 상태 머신(#7) 연결 후 다시 잰다.

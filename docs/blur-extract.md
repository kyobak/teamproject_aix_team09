# 영상 가림과 1fps 추출 (#4)

현재 도구는 **YuNet 얼굴 가림 전용**입니다. Haar 얼굴·번호판 검출을 제거했으며 **번호판은 자동으로 가리지 않습니다**. CVAT 업로드 전에 담당자가 사진 전체를 확인하고 식별 가능한 얼굴·번호판 사진을 제외합니다. 구체적인 처리 절차는 아래 검수 규칙을 따릅니다.

## 실행

최초 한 번 공식 YuNet ONNX 모델을 내려받습니다. 기존 OpenCV 패키지를 그대로 쓰며 추가 Python 라이브러리는 필요하지 않습니다.

```bash
python tools/download_yunet.py
```

Windows에서는 아래 실행 예시와 같이 가상환경 Python 앞에 -X utf8을 붙여도 됩니다.
기본 실행은 YuNet 얼굴 검출만 사용합니다. 모델 파일이 없으면 오류로 알리며 다른 검출기로 대체하지 않습니다.


프로젝트 폴더에서 기존 Python 환경으로 실행합니다.

```powershell
& "..\.venv\Scripts\python.exe" tools/blur.py 입력.mp4 출력.mp4
& "..\.venv\Scripts\python.exe" tools/extract_frames.py 출력.mp4 data/frames/<clip_id>
```

macOS에서는 프로젝트용 가상환경을 활성화한 뒤 다음 명령으로 실행합니다.

```bash
python tools/blur.py 입력.mp4 출력.mp4
python tools/extract_frames.py 출력.mp4 data/frames/clip01
```

위 예시의 clip01을 clips.csv의 해당 clip_id로 바꿉니다.

clip_id는 clips.csv와 맞춥니다. 사진은 000001.jpg부터 순서대로 저장됩니다. 기존 출력 파일이나 비어 있지 않은 사진 폴더에는 덮어쓰지 않습니다. 출력 영상에는 오디오가 포함되지 않습니다.

## CVAT 업로드 전 얼굴·번호판 검수

2026-11-20 팀 안내에 따라 PR #39 리뷰의 (b) 방식인 **식별 가능한 사진 제외**를 적용합니다. YuNet은 얼굴을 놓칠 수 있고 번호판 자동 가림은 없습니다. 자동 블러 결과나 Drive에 있는 파일을 검수 완료로 간주하지 않습니다.

1. 사진 업로드 후 공지되는 클립 분배에 따라 각 담당자가 `frames/<clip_id>/` 전체를 갤러리/큰 아이콘 보기로 확인합니다. 얼굴·번호판 식별 여부가 애매하면 해당 사진을 확대해 확인합니다.
2. 얼굴 또는 번호판을 식별할 수 있는 사진은 **CVAT 업로드에서 제외**하고 `frames/_reject/<clip_id>/`로 이동합니다. 파일명은 바꾸거나 다시 번호를 매기지 않습니다. `_reject`는 CVAT에 넣을 클립 폴더 밖에 두고, 업로드·압축 대상에 포함하지 않습니다.
3. 제외한 `clip_id`, 원래 파일명, 사유(얼굴/번호판), 최초 사진 수와 제외 수를 강태혁에게 공유합니다. `_reject`도 식별 가능한 이미지이므로 라벨링 도구·GitHub·AI 입력으로 전달하지 않습니다.
4. 제외율은 **제외한 고유 사진 수 / 검수 전 해당 클립의 전체 사진 수 × 100**입니다. 얼굴과 번호판이 동시에 보여도 한 사진은 한 번만 셉니다. **10%를 초과하면 클립 전체를 보류**하고 남은 사진도 CVAT에 올리지 않습니다. 정확히 10% 이하라도 남은 사진의 전수 확인이 끝나야 합니다.
5. 보류 클립은 가림 보완 또는 해당 클립 제외 방안을 담당자와 정한 뒤 재검수합니다. 검수 결과를 기록한 통과 사진만 CVAT로 전달합니다.

이 사진 제외율 10%는 개인정보 검수 기준입니다. 원본·블러의 신호 정보 차이 3% 이하 및 위험 방향 차이 0건이라는 #4 기준과는 다른 지표입니다. 개인정보 검수만으로 신호 보존 확인을 완료 처리하지 않습니다.

## 현재 처리 방식

- #2의 frames()로 입력을 읽습니다.
- OpenCV FaceDetectorYN의 YuNet 얼굴 검출만 사용합니다. Haar XML과 캐스케이드 로딩·검출 경로는 없습니다.
- YuNet은 원본 해상도와 BGR 이미지를 입력으로 사용합니다. 신뢰도 기본값은 0.75, NMS 임계값은 0.3입니다. 아래 값은 조정 가능한 초기 설정이며 실제 검수 결과로 판단합니다.
- YuNet은 매 프레임 원본 크기로 얼굴 후보를 찾습니다. 신뢰도와 NMS 설정은 이전 YuNet 구현과 같습니다.
- 검출 박스 양쪽에 폭·높이의 50%씩 여유를 둡니다. 최종 폭·높이는 각각 두 배입니다.
- 직전 두 프레임의 후보도 합쳐서 잠깐의 검출 누락을 보완합니다. 움직이는 얼굴의 추적 기능은 없습니다.
- 후보 영역을 최대 6×6 크기로 축소한 후 가우시안 흐림을 적용해 부드럽게 확대합니다.
- 출력에서 영상 시각의 정수 초가 바뀔 때 한 장씩 추출합니다.

## 비교 및 신호등 영역 보존

기존 --haar-only 옵션과 Python API의 haar_only 인자는 제거했습니다. 예전 명령을 그대로 실행하면 오류가 나므로 해당 옵션을 빼고 실행합니다.

YuNet도 얼굴 오검출이나 누락이 있을 수 있습니다. 공유 전 실제 결과를 확인하며, 신호 인식은 같은 프레임·같은 시각으로 원본과 비교합니다. #4의 현재 기준은 위험 방향 차이 0건(원본 red → 결과 green, 결과에서만 CROSS) 및 신호 정보 차이 3% 이하입니다.

직접 확인한 신호등 영역은 --protect LEFT TOP RIGHT BOTTOM으로 보존할 수 있습니다. 각 좌표는 화면 크기 대비 0~1 사이 비율이고 여러 번 지정할 수 있습니다. 예를 들어 다음은 화면 오른쪽 위 일부를 보존합니다.

```bash
python tools/blur.py 입력.mp4 출력.mp4 --protect 0.7 0 1 0.3
```

이 좌표는 사용법 예시이며 실제 영상의 신호등 위치에 맞춰야 합니다. 카메라가 움직이면 고정 보존 영역이 신호등을 벗어날 수 있고, 보존 영역 안의 얼굴·번호판도 남습니다. 따라서 보호 영역 적용 후에도 담당자가 위 절차로 사진 전체를 다시 검수합니다. 기본값에는 보존 영역을 지정하지 않습니다.

# 영상 가림과 1fps 추출 (#4)

현재 구현은 검수·보완 중입니다. 실제 영상에서 얼굴 누락이 보고됐으므로 결과 영상의 전체 비식별 처리를 보증하지 않습니다.

## 실행

최초 한 번 공식 YuNet ONNX 모델을 내려받습니다. 기존 OpenCV 패키지를 그대로 쓰며 추가 Python 라이브러리는 필요하지 않습니다.

```bash
python tools/download_yunet.py
```

Windows에서는 아래 실행 예시와 같이 가상환경 Python 앞에 -X utf8을 붙여도 됩니다.
기본 실행은 Haar 얼굴·번호판 검출과 YuNet 얼굴 검출을 함께 사용합니다. 모델 파일이 없으면 오류로 알립니다.


프로젝트 폴더에서 기존 Python 환경으로 실행합니다.

```powershell
& "..\.venv\Scripts\python.exe" tools/blur.py 입력.mp4 출력.mp4
& "..\.venv\Scripts\python.exe" tools/extract_frames.py 출력.mp4 data/frames/<clip_id>
```

macOS에서는 프로젝트용 가상환경을 활성화한 뒤 다음 명령으로 실행합니다.

```bash
python tools/blur.py 입력.mp4 출력.mp4
python tools/extract_frames.py 출력.mp4 data/frames/clip01
```

위 예시의 clip01을 clips.csv의 해당 clip_id로 바꿉니다.

clip_id는 clips.csv와 맞춥니다. 사진은 000001.jpg부터 순서대로 저장됩니다. 기존 출력 파일이나 비어 있지 않은 사진 폴더에는 덮어쓰지 않습니다. 출력 영상에는 오디오가 포함되지 않습니다.

## 현재 처리 방식

- #2의 frames()로 입력을 읽습니다.
- OpenCV의 haarcascade_frontalface_default.xml과 haarcascade_russian_plate_number.xml, FaceDetectorYN YuNet 얼굴 검출을 함께 사용합니다.
- YuNet은 원본 해상도와 BGR 이미지를 입력으로 사용합니다. 신뢰도 기본값은 0.75, NMS 임계값은 0.3입니다. 아래 값은 조정 가능한 초기 설정이며 실제 검수 결과로 판단합니다.
- Haar 입력은 회색조 영상을 1.5배 확대하고 히스토그램 평활화를 적용합니다.
- Haar는 scaleFactor=1.08, minNeighbors=50으로, YuNet은 매 프레임 원본 크기로 후보를 찾습니다. 두 검출기 중 하나만 찾은 후보도 합칩니다.
- 검출 박스 양쪽에 폭·높이의 50%씩 여유를 둡니다. 최종 폭·높이는 각각 두 배입니다.
- 직전 두 프레임의 후보도 합쳐서 잠깐의 검출 누락을 보완합니다. 움직이는 얼굴의 추적 기능은 없습니다.
- 후보 영역을 최대 6×6 크기로 축소한 후 가우시안 흐림을 적용해 부드럽게 확대합니다.
- 출력에서 영상 시각의 정수 초가 바뀔 때 한 장씩 추출합니다.

## 비교 및 신호등 영역 보존

Haar만 사용한 비교 결과는 다음 명령으로 만듭니다.

```bash
python tools/blur.py 입력.mp4 Haar결과.mp4 --haar-only
```

두 얼굴 검출기의 결과를 합치면 오검출도 증가할 수 있습니다. 신호등을 얼굴로 오인해 흐리면 신호 인식 결과가 바뀔 수 있습니다. 원본과 결과의 초 단위 신호 인식 비교가 필요합니다.

직접 확인한 신호등 영역은 --protect LEFT TOP RIGHT BOTTOM으로 보존할 수 있습니다. 각 좌표는 화면 크기 대비 0~1 사이 비율이고 여러 번 지정할 수 있습니다. 예를 들어 다음은 화면 오른쪽 위 일부를 보존합니다.

```bash
python tools/blur.py 입력.mp4 출력.mp4 --protect 0.7 0 1 0.3
```

이 좌표는 사용법 예시이며 실제 영상의 신호등 위치에 맞춰야 합니다. 카메라가 움직이면 고정 보존 영역이 신호등을 벗어날 수 있고, 보존 영역 안의 얼굴·번호판도 남습니다. 따라서 보호 영역 적용 후에도 영상 전체와 샘플 50장을 다시 검수합니다. 기본값에는 보존 영역을 지정하지 않습니다.

- Haar+YuNet 통합 후 합성 데이터와 기존 테스트를 포함해 전체 319개 통과. 실제 작은 얼굴·옆얼굴의 식별 불가 여부는 자동 테스트로 확인되지 않습니다.
- 이전 Haar 구현 검수에서는 KakaoTalk_20261108_171052960.mp4의 원본·출력 1,210프레임 일치, 사진 41장을 확인했습니다. 이를 새 구현의 비식별 검수 통과로 사용하지 않습니다.
- 사용자가 실제 영상에서 얼굴 누락을 보고했습니다. 먼 얼굴·옆얼굴 및 한국 번호판의 검출 한계와 오검출을 더 확인해야 합니다.
- 샘플 50장 식별 불가 판정, 전체 결과 검수, clips.csv 대조, 공유 드라이브 전달, 원본 삭제 확인은 미완료입니다.
- 실제 사람 사진을 자동 테스트에 포함하지 않습니다. 검수 결과가 확보된 뒤 완료 여부를 판단합니다.

## 2026-11-12 Haar 감도 조정

- 사용자 요청에 따라 Haar의 minNeighbors만 3에서 8로 높였습니다. 얼굴·번호판 Haar 모두 같은 설정을 사용합니다.
- YuNet 모델·신뢰도 0.75·NMS 0.3과 영역 확장·시간 유지·흐림 강도는 기존 설정을 유지합니다.
- 같은 원본의 0, 1, 3, 10, 20, 30, 36, 40초 각 한 프레임을 비교했습니다.
- 해당 8프레임의 Haar 후보 합계는 174건에서 30건으로 감소했습니다. 이 수치는 오검출 감소나 얼굴 가림 성공률을 직접 측정한 값이 아닙니다.
- Haar 후보가 없어지는 구간에서도 YuNet 결과가 계속 적용되는 회귀 테스트를 보강했으며 전체 319개 테스트가 통과했습니다.

## Haar 감도 추가 조정 (minNeighbors=50)

- 사용자가 Haar를 더 둔하게 조정하도록 요청해 minNeighbors를 8에서 50으로 높였습니다.
- Haar 감도에 절대적인 최솟값이 있는 것은 아닙니다. 현재 값은 반복 검출이 강한 후보만 허용하는 실험 설정입니다.
- YuNet 신뢰도·NMS와 박스 확장·이전 프레임 유지·흐림 강도는 유지했습니다.
- 같은 8개 시점의 Haar 후보 합계는 30건에서 0건으로 줄었습니다. 전체 영상 또는 다른 영상에서도 0건이라는 뜻은 아닙니다.
- 전체 회귀 테스트 319개가 통과했습니다. 실제 얼굴·번호판 검수와 신호 전후 비교는 별도로 판단합니다.

### 전체 영상 재비교 결과 (minNeighbors=50)

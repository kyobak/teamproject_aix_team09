# Ultralytics 라이선스와 사용 범위

- 사용 대상: 선택 의존성 `ultralytics==8.4.213`과 Ultralytics의 COCO 사전학습 YOLO11n 가중치(`yolo11n.pt`).
- 사용 범위: #12의 D1에서 보행 신호등 후보 위치를 검출합니다. 색 판정과 상태 판단은 기존 파이프라인을 사용하며, D0 기본 실행에는 Ultralytics가 필요하지 않습니다.
- Ultralytics가 라이브러리와 공개 모델에 적용한다고 안내하는 라이선스는 AGPL-3.0입니다. [라이선스 전문](ultralytics-AGPL-3.0.txt)은 위 버전 배포 패키지의 LICENSE 파일입니다.
- 가중치는 저장소에 포함하지 않으며 공식 배포본을 로컬에서 받습니다.

출처: [Ultralytics 라이선스 안내](https://www.ultralytics.com/license), [YOLO11 공식 문서](https://docs.ultralytics.com/models/yolo11/).
